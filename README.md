# Enhanced-DOS-BASIC-for-CoCo3

Enhanced DOS BASIC for CoCo 3.

## EDB v15 Tools — confirmed baseline (2026-11-19)

The `EDB_v15_512k_tools.dsk` image is the user-confirmed v15 Tools baseline.

SHA-256: `e919ab51c9716997ea74aaecc54eca79210e0e8701b4a95b7abc3ab54854e142`

### Fixes included

- **DISKCOPY FULL:** Detects 35-track or 40-track media on both drives before the copy, uses the corresponding track count, and rejects mismatched geometries before overwriting the destination.
- **DISKCOPY without arguments:** Prevents the `?FC BUG! AT 580` caused by passing an empty string to `ASC` in the uppercase-conversion routine. An argument-free invocation can now display the command's usage instructions.
- **FIND command-buffer protection:** Checks the command-tail length before inserting its three-byte prefix at `$FC80`. Oversized arguments now exit with `FIND: command too long` rather than overwriting adjacent memory.

Only `DISKCOPY.BAS` and `FIND.BAS` were modified within this Tools image. The user reported that the fixes work in testing. The original Boot disk and all unrelated program files were preserved.

**Repository note:** The `extracted/` directory reflects the earlier disk extraction and has **not** been regenerated by this baseline update. The Tools DSK is the authoritative updated payload; extracted copies of `DISKCOPY.BAS` and `FIND.BAS` are therefore older snapshots.

The authoritative Boot baseline is the user-supplied v15 Boot disk, which differs from the Boot image currently checked into this repository; the Boot file was deliberately not modified by this Tools-only commit.
